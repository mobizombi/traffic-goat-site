## Decision Rule
If outbound reply rate is below 8% after 40 messages:
- Narrow the ICP.
- Make the first line more specific.
- Mention one observed leak earlier.
- Reduce generic brand language.

If content gets impressions but no clicks:
- Make the CTA more direct.
- Add clearer problem examples.
- Move the audit offer higher.

If website gets visits but no inquiries:
- Tighten the audit offer.
- Add proof/examples.
- Add a lower-friction CTA.
