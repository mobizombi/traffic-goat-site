# Traffic Goat - AI Revenue Infrastructure Website

Static premium homepage for Traffic Goat.

## Positioning
Traffic Goat is an AI Revenue Infrastructure Studio that builds:
- Affiliate Infrastructure
- AI Growth Operations
- Monetization Engineering
- Strategic Partnerships

## Files
- index.html - full landing page
- styles.css - responsive premium design
- CODEX_TASKS.md - next tasks for Codex
- OUTREACH.md - first outbound scripts
- CONTENT_PLAN.md - first 30-day content engine

## Run locally
Open index.html in your browser.

Or run:
python3 -m http.server 8080

Then open:
http://localhost:8080
